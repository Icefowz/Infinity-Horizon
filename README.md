# Infinity Horizon

A breathtaking interactive 3D web experience built with Three.js and vanilla JavaScript. Infinity Horizon showcases immersive visual effects including dynamic waves, particle systems, celestial bodies, and interactive animations—all powered by WebGL and GLSL shaders.

## About the Project

Infinity Horizon is a showcase of modern web technologies and creative visual storytelling. The project demonstrates advanced rendering techniques and interactive design patterns, featuring:

- **Interactive 3D Environment** — Explore a dynamic world with responsive interactions
- **Animated Visual Effects** — Waves, particles, stars, and celestial phenomena
- **Film Card Animations** — Beautifully animated service cards with smooth transitions
- **Responsive Design** — Seamless experience across all device sizes
- **Performance Optimized** — Efficient rendering using modern browser APIs

## Technologies Used

### Core Stack
- **HTML5** — Semantic page structure and accessibility attributes
- **CSS3** — Responsive layouts, Grid, Flexbox, gradients, animations, custom properties, masks, and media queries
- **Vanilla JavaScript** — Pure JavaScript without frameworks for lightweight performance

### Graphics & Rendering
- **Three.js 0.180.0** — Loaded from esm.sh for modern 3D graphics
- **WebGL** — Hardware-accelerated graphics rendering
- **GLSL Shaders** — Custom shader programs for visual effects:
  - Wave simulations
  - Particle systems
  - Star fields
  - Sun effects
  - Interactive title animations
  - Dolphin models
  - Meteor effects
  - Film-card animations

### Browser APIs
- **Canvas 2D API** — Generates textures and card imagery for Three.js
- **ResizeObserver** — Responsive canvas resizing
- **IntersectionObserver** — Efficient element visibility detection
- **Font Loading API** — Optimized font loading
- **matchMedia** — Media query detection in JavaScript
- **Pointer Events** — Advanced mouse and touch interactions
- **Dynamic Imports** — Lazy loading of modules

### Design Resources
- **Google Fonts** — Manrope, Noto Sans Display, and GFS Didot
- **Unsplash** — Remote service-card images

## Getting Started

1. Clone the repository
```bash
git clone https://github.com/Icefowz/Infinity-Horizon.git
```

2. Open `index.html` in a modern web browser (Chrome, Firefox, Safari, or Edge)

3. Explore the interactive 3D environment

## Browser Support

Works best in modern browsers with WebGL support:
- Chrome/Chromium 90+
- Firefox 88+
- Safari 14+
- Edge 90+
